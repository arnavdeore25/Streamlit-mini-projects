# Streamlit Mini Projects

A collection of beginner-friendly Streamlit applications built for learning, experimentation, and quick data visualization. Each project focuses on a simple theme and demonstrates core Streamlit features such as filters, charts, widgets, and interactive dashboards.

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

## Getting Started

1. Clone the repository.
2. Open a project folder.
3. Create a virtual environment (optional but recommended).
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Run the app:

```bash
streamlit run app.py
```

For the wildlife dashboard, run the file inside the `Wildlife observation` folder:

```bash
cd "Wildlife observation"
streamlit run main.py
```

## Notes

- Each app is intentionally simple and beginner-friendly.
- The repository is meant for learning and prototyping with Streamlit.
- You can extend any dashboard with additional datasets, custom UI elements, or advanced visualizations.
